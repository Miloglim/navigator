# 运价生产编排器接入计划

> 执行方式：当前会话连续实现和验证，不新增依赖。

**目标：** 定时任务仅入队，独立 worker 完成 DWS 拉取、逐消息解析、权威预检、待审核送审、读回对账和水位提交。

**架构：** 群轮次使用固定群 lane 保序；消息子轮次使用独立 lane。父任务通过持久依赖等待子任务，不占用 worker。来源和图片按轮次隔离；所有 IO 在 transport，字段转换和完整性判断在 services。任何缺证据、解析失败或对账失败均保留水位，不假报 DONE。报价仅写待审核，原文和人工记录保持。

**技术：** Python 标准库、SQLite 控制库、现有 DWS CLI/Codex CLI/ledger_client。
