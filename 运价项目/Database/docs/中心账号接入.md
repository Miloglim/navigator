# 运价库接入 Milogin's 中心 Navigator 账号

状态：2026-10-15 准备中，未切换正式登录，禁止据此删除旧账号。

## 2026-10-26 普通读取鉴权缓存与首屏资源

中心模式下 `/api/auth/status`、`/api/bootstrap`、`/api/master`、运价/舱位读取、账号资料、成长、通知和普通看板摘要等白名单 GET 会复用同一本地会话的 Navigator 准入结果 30 秒。缓存键绑定本地会话和当前中心访问令牌，命中期间不重复调用中心；过期、令牌轮换、登出、改密、撤权或中心明确拒绝时清除。

写操作、导出、管理、监控、账号维护、查价任务和其他未列明接口始终实时验证中心，不读取缓存。因此中心停用、归档或降权对普通读取最多有 30 秒生效延迟，对敏感操作没有额外延迟，这是速度与撤权时效的明确取舍。

页面字体改为同源自托管 WOFF2，不再加载 `fonts.googleapis.com`；字体只包含 UI 使用的 Outfit 与 IBM Plex Mono，Latin Extended 按需加载，中文继续使用系统字体。

容量边界：150 个并发小型 API 可全部完成，但整页仍约 249KB gzip 且每次 `no-store`，要从本机经 SSH 隧道上传。150 个整页冷加载在 45 秒测试窗口内不能全部完成，因此“150 名销售使用”不能等同于“150 人同时首次打开页面”。高并发前应把 HTML/JS/CSS/字体静态资源迁到云端 Caddy 或对象存储，只让小型 API 请求回到本机。

## 2026-10-26 首次改密准入与登录提示

中心桌面登录返回 `identity.mustChangePassword=true` 时，Navigator 先建立只允许认证状态、退出和改密的本地受限会话，不再提前查询 Navigator 产品准入。业务 GET/POST 仍统一返回 `password_change_required`；改密请求会续期中心桌面令牌、校验当前密码并在中心完成改密，成功后撤销本地与中心旧会话。用户用新密码重新登录后才查询产品准入。

匿名登录不区分账号不存在和密码错误，统一显示“账号或密码错误”。只有密码已验证且账号停用/归档时才显示状态提示；已认证但无 Navigator 准入显示“当前账号没有 Navigator 权限”，中心服务故障显示暂不可用。不得为了首次改密把 `/api/navigator/access` 放宽为向未完成改密账号返回业务角色。

## 2026-10-26 超级管理员角色落地

中心 `/api/navigator/access` 对 `identity_admin` 返回 `role=superadmin`，不再降级为普通 `admin`。Navigator 已把 `superadmin` 纳入正式角色契约、SQLite/PostgreSQL 约束和 HTTP 权限表，并为其开放销售、航管、主数据、账号管理、运行中心以及来源群/舱位/公告等受限界面。普通管理员仍不能授予或维护超级管理员账号；留言板仍仅由开发模式开关开放，正式端保持关闭。

## 2026-10-22 中心模式禁止 Navigator 本地初始化

Navigator 在 `center_auth_url` 存在时只使用中心账号和 Navigator 产品准入。`/api/auth/status` 固定返回 `auth_mode=center`、`setup_required=false`，不会因为本机 `operators` 没有带密码的本地管理员而进入首次初始化。账号初始化、密码和产品权限都在中心管理库维护。

网页已彻底移除 setup 模式和 bootstrap token 请求。只有在显式未配置中心地址的旧本地模式下，才允许在服务器控制台执行 `python ops/bootstrap_admin.py --name <账号>`，密码通过 `getpass` 交互输入；登录页始终只显示账号登录。

## 2026-10-22 中心短暂故障保留现有登录

中心网络不可达、续期限流或 5xx 只表示身份服务暂时不可用，不再等同于账号撤销。Navigator 对此返回 HTTP 503 `code=unavailable`，保留本地 `freight_session` 和中心刷新 Cookie；中心恢复后下一次请求继续续期。只有中心明确返回 401/403、续期凭据无效，或管理员改密、撤权、停用账号时，才删除本地会话并要求重新登录。

中心刷新令牌会轮换。同一本地会话有多个并发页面请求时，Navigator 串行执行续期并共享结果，避免两个请求同时消费同一个刷新令牌后把正常会话清掉。

## 目标与边界

- 管理中心统一账号、密码与 Navigator 产品准入；运价库属于 Navigator，不新建第三个产品。中心超级管理员拥有运价库管理员权限。
- 运价库继续持有运价、待审核、发布人、反馈、经验、审计及销售/航管业务权限。中心产品权限不等于搬迁业务数据库。
- 普通用户必须同时满足中心账号有效、Navigator 产品授权有效、运价库业务角色有效。停用或撤权须阻断新请求，不能仅在登录时检查。
- 旧邮箱账号须按已验证邮箱与中心稳定 userId 显式配对；同名、同显示名称不能自动合并。发布人姓名不是登录身份。
