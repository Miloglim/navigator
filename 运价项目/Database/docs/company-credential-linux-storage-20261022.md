# 公司查价凭据跨平台加密存储

## 问题

公司查价凭据原先只实现 Windows DPAPI。正式 Navigator 部署到 Ubuntu 后，保存令牌返回“公司接口凭据加密仅支持Windows”，后续自动刷新也无法持久保存。

## 修复

- Windows 继续使用 DPAPI，不改变现有格式和路径。
- Linux 使用独立 64 字节主密钥、OpenSSL AES-256-CBC/PBKDF2 和 HMAC-SHA256 完整性校验。主密钥只生成一次，权限 `600`；密文权限 `600`。
- Linux 持久目录改为中心发布目录下的 `.runtime/MiloginNavigator`，容器重启和 `nav-api` 重建不会丢失。
- 明文令牌不写入 URL、日志、页面、数据库或密文文件；接口仍只返回 user_id、配置状态和更新时间。
- 密文被修改或主密钥不匹配时拒绝解密；凭据管理员绑定和 Windows ACL边界保持不变。

## 验证

- Windows 定向测试 6 项通过（Linux 用例按平台跳过）；令牌刷新 4 项、凭据 HTTP 1 项通过。
- 正式 Linux 容器使用合成令牌完成保存/读取，确认明文不在文件中、密文与主密钥均为 `600`。
- 部署后需在管理中心重新保存公司业务用户 ID 和令牌，再验证知识库自动刷新与真实公司查价。
