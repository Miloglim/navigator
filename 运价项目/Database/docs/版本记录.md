# 版本记录

## 运价采集编排器 0.5.0 - 2026-10-21

- 新增独立 Trace Studio `/studio`，提供生产树、消息与阶段下钻、失败原因、原文/原图证据、产品闭环矩阵、事件流和阶段级恢复入口。
- 新增 `/api/trace/roots`、`/api/trace/run`、`/api/trace/stream`、`/api/trace/image`、`/api/trace/action`；SSE 只触发界面刷新，不携带业务指令。
- 根节点优先展示同群失败/阻塞轮次，避免后续排队或合并触发掩盖真实问题；恢复操作仅复用既有任务方法，不增加自动放行或正式业务写入。

## 6.48.0 - 2026-10-21

- 新增 Prospector Windows 客户端公开下载页、稳定版清单接口和安装包流式下载，不影响运价查询、审核、中心鉴权或采集写入。
- 下载文件和清单放入 `.runtime/downloads/prospector`，支持 `NAVIGATOR_DOWNLOADS_DIR` 覆盖；只发送当前清单登记的唯一安装包并展示 SHA256、大小、系统要求和签名状态。
- Prospector 增加正式打包并写入 Navigator 下载目录的脚本；执行后无需重启 Navigator。

## 6.47.0 - 2026-10-21

- 新增 `POST /api/agent/intake/v1`，外部解析 Agent 使用独立 Bearer Token 提交版本化标准 JSON，服务端强制 `origin=agent` 并复用待审核校验，不直接写正式运价/舱位表。
- 新增 `Skill/navigator-agent-intake/`，包含完整字段契约、调用边界和标准库提交脚本；每次请求必须带 `来源群`、`消息ID`、逐字 `消息原文`。
- 部署候选包同步纳入新接口服务端代码和外部 Agent Skill，不包含真实 Token。
