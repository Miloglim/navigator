# 销售端查询栏改造规范（重排 + 提交式 + 多值标签 + 最新排序）

> 目标：销售端查询以「起运港 / 目的港 / 承运人」为主查询三件套，其余收进「高级筛选」；
> 三个主查询字段**提交式**（回车或点候选/查询才生效，不边打边查）；起运港、目的港支持**多值标签**，
> 两者都多值时按 **AND 取交集**（各自内部 OR）；运价默认**按最新条目排序**。
> 港群在查询命中层保持双向展开（查成员港带出群价）——本轮**不动**展开，只收敛输入框干扰。

涉及文件：`web/index.html`（查询栏 HTML/CSS/JS）、`manualdb.py`（`_where` 支持多值 pol/pod）、`manual_check.py`（多值查询回归）。

---

## 1. 查询栏重排（HTML）

主行（常驻）：
```
[起运港 标签框]  [目的港 标签框]  [承运人 提交框]  [查询]  [高级筛选 ▾]
```
- 「船司」字面改「**承运人**」（label 改文案，字段键 carrier 不变）。
- 记录类型切换仍由 `cat-tabs`（运价/舱位/动态/来源群）承担；筛选栏里的 `sf-tab` select 改为 `display:none` 只存状态（`setCatTab`/`onTabChange` 不变）。

高级筛选（默认折叠，点「高级筛选」展开）：航线 / 柜型 / 来源群 / 舱位类型(舱位tab时) / 有效期 / 消息时间起 / 消息时间止。

## 2. 提交式查询（三主字段）

- 起运港、目的港、承运人**只有提交才进查询**：回车、点联想候选、或点「查询」按钮。只敲字不提交 → 不落任何查询值。
- 提交时**归一到主数据规范名**：港口走 `S.portIdx`（foldKey），承运人走 `S.carrierIdx`（青岛→Qingdao、达飞→CMA），归一不到就按原样（后端再校）。
- 提交值存 `S.sales.polTags[] / podTags[] / carrier`；`salesLoad` 只读这些已提交值，不读输入框原始文本。

## 3. 起运港 / 目的港 多值标签

- 标签框 = 已提交值渲染成 chip（带 × 删除）+ 一个可继续输入的 text 框（保留 `data-ac` 联想、`data-nogroup` 不列港群候选）。
- 回车 / 点候选 → 把当前输入归一后**追加为一个 chip**（去重），清空输入框，继续可输下一个 → 复数查询。
- chip 的 × 用事件委托删除（避免值含引号/括号如 `Manzanillo(MX)` 的内联转义问题）。
- **交集语义**：`pol` 多值内部 OR、`pod` 多值内部 OR，两字段都有值时 **AND**（结果 = 命中任一 pol 且命中任一 pod 的行）。前端把多值用英文逗号 join 传 `pol=` / `pod=`；后端按逗号拆分。

## 4. 后端多值（manualdb._where）

`pol`/`pod` 值可能是逗号分隔多值。新增 `_multi_filter`：对每个 token 走既有 `port_filter`（保留群↔成员双向展开），各 token 的 frag 用 `OR` 合并成一个 `(...)`；`nogroup` 语义保留（每 token 退化为 `col=?`）。carrier 仍单值。
- 单值调用完全兼容（一个 token → 等价原行为），既有回归不受影响。

## 5. 运价默认按最新排序

- 后端 `query`/`query_grouped` 已 `ORDER BY message_time DESC, id DESC`（行级最新在前）。
- 前端折叠视图 `renderSalesFolded`：航线分组顺序改为**按组内最新消息时间倒序**（最新活动的航线组排最前），取代固定 `ROUTE_ORDER` 优先；`NO_ROUTE` 仍殿后。

## 6. 验收

1. `python manual_check.py` 全绿（含新增多值查询用例）。
2. 查询栏主行只有 起运港/目的港/承运人 + 查询 + 高级筛选；「船司」显示为「承运人」。
3. 起运港敲 `shekou` 回车 → 变 chip；再敲 `ningbo` 回车 → 两个 chip；点 × 可删。
4. 只敲字不回车/不点查询 → 查询值不变（结果不随输入实时变）。
5. 起运港 {Shekou,Ningbo} + 目的港 {Santos} → 结果只含 (Shekou|Ningbo) 且 Santos 的行（交集）。
6. 敲中文 `青岛` 回车 → chip 显示规范名 `Qingdao`，查询按规范名命中。
7. 高级筛选默认折叠，展开后航线/柜型/来源群/舱位类型/有效期/消息时间可见可用。
8. 运价默认列表最新条目在最前。
9. 查成员港（如 Pecém）仍带出群价（NEB）条目——展开未被破坏。
