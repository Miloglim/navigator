## 已确认模板

- `船司 + 起运港 + 成本 + 路线/周期 + 船名航次 + 目的港 + 金额 + LSS/CC`：逐港拆产品，附加费写备注。
- `更新 + 船司 + 航线 + 金额/金额`：按目的港逐行拆分，船名航次以原文为准。
- `图片现舱更新`：先识图；有价行运价与舱位双入，无价行只入舱位。

## 已知坑

- `JKT&SUB2400` 这类紧凑写法先分目的港和金额；不得把 `JKT&SUB` 当成一个港口。
- `45尺` 对应 45HQ/HC，不映射成 40HQ/HC；LSS/CC 另行保留。
- `USD510/930` 两个金额若正文和船期表都没有柜型列位，只能保留待核，不能按金额大小猜 20GP/40HQ。
- 一张表用两个多起运港合并列给出同价时，先确认是否应建港群；只有原文明确绑定的船期航线才按具体起运港落待审。
- `Katupalli` 是独立目的港，不并入 Chennai；`Semarang`、`Cikarang Dry Port` 不并入 Jakarta。
