## 已确认模板

- `[图片] + 船司 + 指导报价/成本`：逐图读取港口、柜型、金额、有效期和船期，图题中的船司与价格口径写入证据/备注。
- `船司 + 目的港 + 数值/数值 + 日期`：按原文顺序拆柜型；不得只取前两档而漏掉原文明示的第三档。
- `SLOT + 航次 + 日期`：只生成船期舱位事实；没有明确可订舱状态或运价时，不生成空价舱位。
- “涨/降 + 数值/数值”但没有完整目的港或柜型的产品，保留消息与证据，不猜完整报价。

- 图片标题里的 `TSLINE 指导报价`、`OOCL 成本` 是价格性质证据，不能丢成普通备注。
